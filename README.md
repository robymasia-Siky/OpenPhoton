# OpenPhoton (MIT)

Open-source C++20 VST3 audio stem separation & restoration plugin powered by **ONNX Runtime (GPU CUDA)**, lock-free stem caching, and priority chunk scheduling (*Preview from anywhere*).

Compatible with **Ableton Live 12 Suite** and **Nota DAW** (VST3).

## Automatic Cloud Build
Every push to `main` triggers `.github/workflows/build-windows.yml` and produces `OpenPhoton-Win64-VST3` in **GitHub Actions -> Artifacts**.
